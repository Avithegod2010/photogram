# Security policy

## Reporting a vulnerability

Please report security issues privately, not in a public issue:

- Open a private advisory: https://github.com/AviTheGod2010/photogram/security/advisories/new

Include what you did, what happened, and the version you tested. I aim to acknowledge
within a week. This is a personal project with no bug bounty, so please do not expect payment.

## Supported versions

Fixes land on the latest release. Older versions are not maintained.

## Scope

In scope: anything in this repository that compromises the user's data, device or accounts.
Out of scope: findings that require a rooted device or physical access with an unlocked bootloader
unless the repository explicitly claims protection against that.
